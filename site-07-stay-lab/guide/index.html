Stay Lab: how this concept was built

Experimental service lab for a single-property vacation rental business, optimized for Vercel static hosting and video-friendly presentation.

Creative brief

Primary angle: innovation.

Mood: acid yellow, black, mint.

Motion: modular grids, split-screen experiments, cursor-responsive cards.

#f4ff00#101010#ffffff#00c2a8

Build method

The route is generated from shared structured data in generate-sites.mjs. The page reuses local property photos, a global stylesheet, and one small JavaScript file for progressive interactions.

For Vercel, each concept lives in its own folder with an index.html, so clean URLs work without a server framework.

Iteration pass 1

Checked the first viewport for a clear property image, direct business positioning, readable contrast, and a visible conversion path.

Iteration pass 2

Improved the visual system by making palette, spacing, typography tone, and motion language distinct from the other nine concepts.

Iteration pass 3

Reviewed responsive layout, reduced-motion behavior, image loading priority, guide completeness, and Vercel route structure.
