Build guide

How the 10-site vacation rental showcase was built.

This project uses a static generator to create a hub, ten concept websites, and ten matching guide routes from one structured source of truth.

Workflow

1. Audited the existing Central Island Home page and local photo assets.

2. Defined ten different visual directions for a single-property vacation rental and future management company.

3. Generated static routes that Vercel can serve directly with clean URLs.

4. Added a guide route for every concept plus this master guide.

Performance decisions

The hero image is discoverable in HTML and marked high priority. Below-fold images use native lazy loading. Animations are primarily transform and opacity, and reduced-motion preferences are respected.
